# ARIA Voice Robot

## Overview

I developed this project during my internship at iSpark Learning Solutions as part of my work in AI-based service robotics.

ARIA Voice Robot is a Voice-to-Voice AI service robot built using Python and Raspberry Pi 5. The robot listens to the user's voice, converts speech to text, processes the request using AI, and responds through speech. The project can also be integrated with a 6 DOF robotic arm for service robotics applications.

## Features

- Voice-to-Voice interaction
- Speech-to-Text conversion
- AI-powered chatbot
- Text-to-Speech response
- Raspberry Pi 5 integration
- 6 DOF robotic arm support

## Technologies Used

- Python
- Raspberry Pi 5
- Google Gemini API
- SpeechRecognition
- pyttsx3
- PyAudio

## Hardware Used

- Raspberry Pi 5
- USB Microphone
- Speaker
- 6 DOF Robotic Arm

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Run the project using:

```bash
python aria_robot.py
```
